# IE-CAPM: self-review, claim boundary, and implementation

## Decision

Implement **Image-Evidence Calibrated CAPM (IE-CAPM)** as a journal candidate,
but not as a causal adjustment or a scan-domain generalization method.  CAPM's
repeated strong performance with both complete tables and demographics-only
tables is sufficient motivation to treat it as the fusion backbone.  It is not
evidence that any individual CAPM modulation is reliable.

IE-CAPM asks a narrower question: *where does the MRI feature map support the
spatial modulation proposed by each observed table variable?*

## Model

At one ResNet stage, let \(F\in\mathbb{R}^{C\times D\times H\times W}\), let
\(F_{img}\) be the matching feature from a shared-weight, table-free image
stream, and let the CAPM field for observed variable \(z_v\) be \(r_v(z_v)\).
IE-CAPM is

\[
 g_v(F_{img})=\sigma(q_v(F_{img})),\qquad
 m(F,z)=\sigma\!\left(\sum_{v=1}^{V} g_v(F)r_v(z_v)\right),
\]

\[
 F'=F+\operatorname{Norm}((1-m(F,z))\odot F).
\]

`q_v` is a 1x1x1 convolutional network whose only input is \(F_{img}\), not
\(z\) or an earlier CAPM-adjusted feature.  The table-free stream shares the
visual ResNet weights with the conditioned stream but is never modulated.
The conditional field \(r_v\) is still generated by CAPM's RBF/embedding plus
variable-specific spatial bases.  In the implementation, the total basis count
is exactly the sum of the per-variable counts; the legacy default requested 34
bases while allocating 32, which is incompatible.

## Self-review

| Question | Review result | Design response |
| --- | --- | --- |
| Is this merely CAPM plus an attention layer? | At a superficial level it is. The nontrivial restriction is that the gate is variable-indexed, table-free, and gates CAPM's *pre-sigmoid variable fields* before they combine. | Compare against CAPM, CAPM plus one shared image gate, and table-conditioned gate. |
| Can the gate collapse to zero and silently discard tables? | Yes, an unconstrained multiplicative gate can. | Initialise at 0.95, expose an exact gate=1 CAPM control, and add gate-anchor, gate-floor, and effective-modulation-preservation losses. |
| Does it remove demographic bias? | Not automatically. Some demographic and clinical variables are predictive by design; forced invariance would be scientifically wrong. | Claim calibrated fusion and report subgroup/attribute-swap sensitivity as audits, not a blanket invariance objective. |
| Is a causal claim justified? | No. Neither scan parameters nor causal confounder relations are identifiable across ADNI/NACC here. | Do not use causal, intervention, or scanner-correction language. |
| Is it engineerable? | Yes, with a known cost: gated training propagates a shared-weight table-free visual branch in addition to the conditioned branch. It exposes stage-level gates/fields for analysis. | New code is self-contained in `Model/backbone/evidence_calibrated_capm.py`; it does not depend on the absent legacy `Model.causal.sca_capm`. |

## Required evidence before a journal claim

1. Use identical patient-level splits, preprocessing, backbone capacity, and
   hyperparameter budget for CAPM and IE-CAPM.
2. Report CAPM, IE-CAPM, the exact `force_capm=True` control, a shared-gate
   ablation, and a table-conditioned-gate ablation.
3. Report repeated-seed confidence intervals and paired per-subject changes;
   do not select the claim on a single external split.
4. For each table regime (complete table and demographics-only), show gate
   distributions by diagnosis and cohort, plus performance after plausible
   attribute permutations.  Clinical variables such as MMSE must be discussed
   separately from demographics rather than treated as nuisances.
5. A publishable mechanism statement requires both stable performance gain and
   reproducible gate/field patterns.  Accuracy alone is not a mechanism result.

## Interface

```python
from Model.backbone.evidence_calibrated_capm import resnet18_ie_capm

model = resnet18_ie_capm(txt_dim=9, num_classes=3, var_specs=my_var_specs)
logits, audit = model(mri, table, return_audit=True)
loss_terms = model.regularization_losses()

# Strict CAPM-equivalent computation, using the same learned CAPM fields.
capm_logits = model(mri, table, force_capm=True)
```

The training objective should begin with classification loss plus modest,
pre-registered weights on the named regularizers.  It should not apply a
generic attribute-invariance loss to MMSE, CDRSB, ADAS11, or FAQ.
