# 待做事项一：1.5T/3T 的特征尺度依赖与跨场强泛化猜想

状态：待验证的核心猜想，不是当前结论。

本待做事项必须遵循 `SCAN_AWARE_DATA_REALITY_AND_CLAIM_BOUNDARY.md` 的数据现实与主张边界。尤其是，NACC 仅含 3T 扫描，且协议近乎单一；因此 NACC 3T 到 ADNI 1.5T 的结果只能作为未支持协议（unsupported protocol）压力测试，不能被解释为模型已经学习到连续的场强响应或完成了 3T 到 1.5T 的校正。

## 1. 猜想内容

3T MRI 通常具有较高信噪比及更丰富的局部空间细节。对于 MCI vs AD 等任务，若模型在 3T 数据中依赖高频纹理、局部边界或细小形态差异，它可能在 3T 目标域中保持较好表现，但在 1.5T 图像中因这些线索衰减、模糊或不可见而显著退化。

相对地，1.5T 图像的有效可见信息较粗粒度；在其上训练的模型可能更依赖海马萎缩、脑室扩大、皮层整体形态等跨分辨率更稳定的全局或中尺度表征。然而，这不推出该模型必然在 3T 上表现较差：若预处理和分布对齐充分，3T 仍保留这些全局信息。观察到的反向退化也可能来自协议、厂家、站点、重建或队列分布的混杂，而非模型使用了更“语义化”的特征。

该猜想的可检验部分是：高频/局部特征依赖是否会增加同一受试者在 1.5T 与 3T 间的预测及表征不稳定性，并使模型对 1.5T 的迁移更脆弱。它不是关于 AD 病灶一定存在于细微纹理中的断言，也不等价于从低场强图像可靠推断高场强中的未知信息。

## 2. 可能的验证思路

1. 在训练集之外保留 ADNI 同一受试者的 1.5T/3T 配对扫描，以 subject 为独立单位；避免纵向重复扫描造成信息泄漏。
2. 构建并比较特征尺度受控的图像模型：低频/全局模型、高频/纹理敏感模型，以及多尺度模型。用统一重采样、低通滤波、高通抑制或纹理扰动控制可用的空间频率，而不是只比较两个黑箱架构。
3. 对每个模型同时报告配对预测概率差 `|p_1.5T - p_3T|`、配对 embedding distance、prediction agreement 和诊断判别力。不能仅凭一致性判断优劣，须防止常数输出造成虚假一致性。
4. 按预定义终点分开报告：`target_full`、`target_common_support_3T`、`target_unsupported_protocol` 和 paired field-strength consistency。NACC 3T 到 ADNI 1.5T 仅作为 unsupported-protocol stress test，不计入主要成功结论。
5. 加入 clean image-only、scan-only、missingness-only、acquisition shuffle、image+scan concat 和 bounded FiLM 等负对照。若 scan-only 或随机打乱 acquisition 信息也能带来类似结果，则不能把性能差异归因于真实的成像机制或特征尺度。
6. 在 ADNI 内以 manufacturer x field-strength x sequence-family 定义 protocol cluster，并执行 leave-one-protocol-cluster-out。只有在尽可能控制协议混杂后仍复现“高频依赖增加跨场强不稳定性”，该解释才更可信。

## 3. 对于模型构建的影响

- 模型应显式评估并约束跨场强的表征与预测稳定性，同时保留诊断可分性；优先采用 paired protocol consistency，而不是要求模型从 1.5T 幻觉式地恢复 3T 细节。
- 训练中应提供尺度稳健性设计，例如多尺度特征融合、受控的频率增强/抑制、分辨率标准化和跨协议一致性损失；具体方法须通过上述受控消融验证，不能仅凭架构直觉宣称有效。
- scan 元数据适合用于定义协议环境、支持集、距离和门控，而不应作为无约束诊断捷径。对于 source 支持集外的协议，模型应回退到 image-only clean path，并输出 unsupported 状态与不确定性。
- 结果解释必须区分“在观测协议共同支持范围内降低预测不稳定性”与“学习到场强的因果响应”。当前数据只允许支持前者，不能支持后者。

# 待做事项二：临床条件化的空间语义特征融合猜想

状态：待验证的核心猜想，不是当前结论。

本待做事项关注结构 MRI 与临床表格信息的交互位置和交互粒度。它不主张简单增加一个 attention 模块即可获得创新或泛化收益；任何优势都必须在相同 backbone、数据划分、训练预算和多个随机种子下通过机制实验确认。

## 1. 猜想内容

对于结构 MRI 与年龄、性别、生化指标或临床评分等表格信息的联合建模，多模态信息如果在空间语义聚合之前发生交互，可能比在 Global Average Pooling 之后进行 concat 更有效。

设深层 CNN 输出的 feature map 为 `F = {x_1, ..., x_N}`，其中每个 `x_i` 是保留空间位置的深层语义 token，而不是原始像素。传统融合通常先执行：

```text
F -> GAP(F) -> concat(image feature, tabular feature) -> prediction
```

这会在表格信息参与之前丢失局部空间结构。待验证的替代机制是让患者条件参与每个空间 token 的调整：

```text
x'_i = f(x_i, t, p_i)
F' = {x'_1, ..., x'_N}
F' -> spatial aggregation -> prediction
```

其中 `t` 表示患者临床背景，`p_i` 表示空间位置。该机制的含义是：同一个局部影像模式在不同临床背景下可能具有不同的诊断意义，临床信息可以在空间聚合前改变局部区域的表示或重要性。

因此，核心猜想是：

> Multimodal information should interact before spatial semantic aggregation rather than after global representation collapse.

该猜想还包含三个子问题：最佳交互层级是否位于中深层 feature map；最佳推理单位是单个 spatial token、固定 patch 还是自适应语义区域；局部 token 的调整是否应同时由局部视觉内容、全局视觉上下文、临床条件和空间位置决定。

## 2. 可能的验证思路

1. 在完全相同的 backbone、训练/验证/测试 subject 划分、优化器、训练轮数和随机种子下，比较 image-only、GAP 后 concat、pooling 前 FiLM、one-token cross-attention、multi-token cross-attention 与临床条件化 patch/token refinement。
2. 对 feature-map stage 做系统消融，例如比较 `C3`、`C4`、`C5`；对空间粒度比较 `1x1`、`2x2`、`4x4` 和 adaptive semantic token，检验是否存在 semantic-resolution sweet spot。
3. 进行 tabular shuffle 对照：保持图像和标签不变，随机打乱患者与表格信息的对应关系。如果提升来自真实的局部图像与临床条件交互，打乱后性能和局部调制模式应明显退化。
4. 对表格变量进行逐变量或分组消融，并比较单一 tabular token 与变量级 token。单一 token 的 cross-attention 可能在数学上退化为对所有 image token 注入同一个 value，因此不能把它与真正的多变量选择机制混为一谈。
5. 报告不仅包括 balanced accuracy、AUROC、F1 和置信区间，还包括 token-level modulation magnitude、区域重要性变化、不同临床亚组的性能，以及 pooling 前后空间信息保留程度。
6. 检验性能提升是否独立于参数量和正则化效应：加入容量匹配的 MLP、参数量匹配的 image-only 模块和 shuffled-tabular control。若随机表格或容量匹配模块也能复现提升，则不能归因于条件化空间融合。
7. 使用 subject-level 划分和多次重复实验，避免同一受试者的纵向扫描或重复扫描跨越训练和测试集合。跨 ADNI/NACC 的结论还应按 common-support 与 unsupported protocol 分层报告。

## 3. 对于模型构建的影响

- 多模态融合的默认位置不应只放在最终分类器之前；模型应允许临床条件在空间结构尚未被 pooling 消除时参与 token refinement。
- 优先研究 `delta x_i = f(x_i, t, p_i)` 形式的内容依赖、位置依赖和患者依赖调制，而不是简单的 `F + t`、无约束 concat 或标准单条件 FiLM。
- 建议保留中间 feature map 的空间结构，并将 CNN 视为生成 data-dependent semantic spatial lattice 的 tokenizer；attention 或条件推理应在经过局部特征提取、但尚未完全聚合的层级执行。
- 临床变量只能作为受约束的条件信息使用，必须防止年龄、诊断相关缺失模式、站点或队列身份成为 shortcut。应同时报告 image-only、tabular-only、missingness-only 和 shuffled-tabular 结果。
- 解释性目标应从“模型关注哪个区域”推进到“不同临床条件是否以可重复方式改变不同区域的表示”，但不能仅凭 attention map 或 Grad-CAM 声称发现了病灶。
- 若实验支持该猜想，方法主张应表述为“在空间语义聚合前进行临床条件化特征交互有助于多模态预测”，而不是宣称该结构普遍优于所有 concat 或 cross-attention 方法。
